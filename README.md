# Rèn Luyện Tư Duy Trẻ Em 🎓

Website học tập tương tác giúp trẻ em (từ 4 tuổi trở lên) rèn luyện tư duy, học toán, tiếng Việt và chơi các trò chơi giáo dục.

## 🌟 Tính Năng

### 📚 Học Tập
- **Toán Học**: Học đếm số, cộng, trừ với hình ảnh minh họa sinh động
  - Đếm số (4-5 tuổi)
  - Phép cộng (5-6 tuổi)
  - Phép trừ (6-7 tuổi)
  - Trộn lẫn (7+ tuổi)

- **Tiếng Việt**: Học bảng chữ cái, từ vựng và ghép câu
  - Bảng chữ cái tiếng Việt đầy đủ
  - Học từ vựng với hình ảnh
  - Bài tập ghép câu
  - Trắc nghiệm kiểm tra

### 🎮 Trò Chơi Trí Tuệ
- **Trò Chơi Trí Nhớ**: Tìm các cặp thẻ giống nhau
- **Tìm Quy Luật**: Hoàn thành dãy số theo quy luật
- **Xếp Số**: Sắp xếp các số theo thứ tự (số puzzle)

## 🚀 Cách Sử Dụng

### Chạy Trực Tiếp
1. Mở file `index.html` bằng trình duyệt web
2. Không cần cài đặt thêm gì!

### Chạy Với Web Server (Khuyến nghị)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (với http-server)
npx http-server
```

Sau đó mở trình duyệt và truy cập: `http://localhost:8000`
